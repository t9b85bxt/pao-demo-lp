# 片づけ・解体のパオ ｜ デモ LP

株式会社パオ（福島県郡山市／片づけ・不用品回収・解体工事）向けに制作した提案用デモ・ランディングページです。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | LP 本体（HTML / CSS / JS をすべて内包した単一ファイル） |
| `ph-*.jpg` | 各セクションの写真（差し替え前提の仮素材） |

外部ライブラリなし・ビルド不要。`index.html` と `ph-*.jpg` を同じ階層に置けばそのまま動きます。

## ローカルで確認

```bash
python -m http.server 4173
# http://localhost:4173/index.html
```

## デプロイ

静的ホスティング（GitHub Pages / Cloudflare Pages / Netlify など）にそのまま配置できます。

- **GitHub Pages**: Settings → Pages → Branch: `main` / `/ (root)`

## 備考

- 写真・ロゴは仮素材です。正式素材に差し替えてください。
- 会社所在地・許認可番号など、掲載情報は公開前に要確認です。
- 本ページは提案用の制作イメージ（デモ）です。
